## Instructions

Have a look through the conversation and create a brief description of what you were dealing with (or whatever the user asks of you when sending the devlog related prompt) in the following format:

Problem:
What issue you ran into. Any error messages, unexpected behavior etc.

Steps taken:
What was done in attempt to solve it. Skip any that are part of the final solution, I don't want them to be duplicated. You can skip this section of there was only one step taken that solved this. 

Solution:
What finally resolved the issue.
